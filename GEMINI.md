# Cyrux Studio UI & Design Directives

This repository enforces high-fashion archival atelier minimalism for Cyrux Studio.

## 1. Cyrux Pure UI Standard (Mandatory & Always Active)
- **Zero Tactical Tech / HUD Clutter**: Under no circumstance add sci-fi HUD reticles, crosshairs, corner ticks (`⌜ ⌝`), coordinates, telemetry boxes, or military/gaming gadgets. The aesthetic is strict high-fashion archival atelier streetwear (pure raw cotton, monumental typography, bone `#FAF8F3` & jet black `#0A0A0A`).
- **Zero Filler / Fluff Text ("Gereksiz Yazılar")**: No fake technical jargon ("SPEC_OPS", "SYSTEM_ACTIVE", "LAT_LONG_HUD", "TELEMETRY", "GRID_REF_0099"). All copy must be restrained, authentic, and purposeful.
- **Zero Double Slashes ("//")**: Absolutely NEVER use `//` in user-facing UI text, headers, badges, or dividers (e.g. `// ARCHIVE`, `// CHAPTER 00`, `// 2026`). Use `•`, `—`, `[01]`, or natural whitespace.
- **Active Skill**: Always adhere to the `cyrux-pure-ui` skill for all frontend, design, and styling tasks.
- **Zero Build Spam**: Never run `npm run build` during iterative changes. Only verify with `npm run typecheck` and `npm test`.
